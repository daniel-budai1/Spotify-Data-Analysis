Why I made this - I decided to work on this as it was part of one of my exams in my first college year in software development, I struggled a lot and never understood pandas from the lessons we took, so I took it upon myself and worked on improving my pandas and OS libraries knowledge and made this data analysis of the most streamed songs worldwide in both Spotify and apple music.


How it works - the user runs the program and it asks the user to choose an option of 4 numbers showing what they will display. For example, if the user chooses the 1st option, the top 10 most streamed songs will be displayed and so on, the info from the chosen option will first be displayed in the terminal then in a graph using the matplotlib library and this goes for all the other options.

Little heads up, make sure the csv file is in the same place as the python file.
